# Манты №1 — заказы кафе в Telegram

Витрина проекта: **https://seinokojii.github.io/manty-demo/**

Telegram-бот и Mini App для кафе в Калининграде: гость собирает заказ в чате,
владелец ведёт его с телефона — принят, готовится, готов. Два филиала, три языка,
оплата по QR.

На странице:

- запись работающей системы (1 минута 42 секунды, без монтажных склеек);
- демо-версия приложения с настоящим меню и фотографиями кафе — работает прямо
  в браузере, заказы существуют только на странице;
- разбор путей гостя и владельца и инженерной части.

Код самого приложения (TypeScript, Next.js, grammY, PostgreSQL, Docker) остаётся
в приватном репозитории.
